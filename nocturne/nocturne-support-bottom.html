Quick checks before you write

  • Open your store in a private browser window. If the problem goes away, clear your browser cache.
  • If you recently added an app, turn it off and check the page again. Apps can add code that changes how a theme behaves.
  • If a menu picture does not show in the Index, check that the Navigation item title matches the menu link exactly. Pictures show on screens 990 pixels wide and up.
  • If the cart drawer does not open, check that Cart type is set to Drawer in Theme settings.
  • If a collection has no filters, turn on Enable filtering in the Collection section and set up filters in the Shopify Search and Discovery app.
  • If color swatches show as text, the option must be named Color or Colour and its values need swatch colors in Shopify.
  • The documentation has a longer troubleshooting list for the header, products, cart and search.
