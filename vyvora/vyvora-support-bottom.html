Try these first

  • Open your store in a private browser window. If the problem goes away, clear your browser cache.
  • Turn off any app you added recently, then check the page again. App code can change how a theme behaves.
  • Index menu empty? Choose a menu in the Header section under Menu.
  • Menu picture missing? The Main menu link name in the Menu image block must match the menu link exactly.
  • Sizes showing as plain buttons? Name the product option Size so it shows as size tiles.
  • Build the fit not showing? At least two slots need products or a collection.
  • No filters on a collection? Turn on Enable filtering and add filters in the Shopify Search and Discovery app.
