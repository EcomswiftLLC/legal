It can miss things, and a result of "No warning signs" is not a promise that a site, file or message is safe or genuine. Always read the address, only continue if you trust where the code came from, and never enter passwords or payment details on a page you reached from a code you do not trust. The App never opens a link by itself, and we are not responsible for the content of sites, apps or files that a code leads to.

Codes you make with the App are checked for readability, but you should test a printed code with another phone before you rely on it. We do not guarantee that every scanner will read every style.
